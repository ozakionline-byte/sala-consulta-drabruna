📝 Transcrição

Ao terminar, clique em Transcrever áudio. Requer uma chave gratuita do Groq configurada no Cloudflare.

O áudio é mantido somente neste navegador até você fechar a página. Na transcrição, o arquivo é enviado à API Groq para processamento. Nenhum histórico é armazenado pelo protótipo.

Como testar

1. Publique a pasta public no Cloudflare Pages com a função functions/api/transcribe.js na raiz do repositório. 2. Configure o segredo GROQ_API_KEY. 3. Inicie uma sala e envie o convite. 4. Com autorização, grave a aba com áudio. 5. Pare a gravação e transcreva. Para testes sem Groq, a sala de vídeo e a gravação funcionam separadamente.
